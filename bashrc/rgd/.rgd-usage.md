# rgd - Fast Whole-Word Ripgrep Search

Searches target files (defaulting to the current working directory) for one or more whole words, ignoring `.gitignore` rules, skipping symlinks/junctions, and deduplicating results while preserving terminal colors and grouped file headings.

## Syntax
    rgd <filename_or_glob> <word1,word2,...> [search_directory]

## Arguments
* **filename_or_glob** (Required): Case-insensitive exact filename or wildcard glob pattern (wrap globs in quotes, e.g., `"*check.log"`).
* **word1,word2,...** (Required): Single word or comma-separated list of whole words to match (case-insensitive; matches whole words only).
* **search_directory** (Optional): Target folder path to search. Defaults to the current working directory (`.`).

## Flags
* `-h`, `--help` : Display this usage guide in the terminal.

## Behavior & Features
* **Case-insensitive matching:** Both filename patterns (`--iglob`) and search words (`-i`) ignore letter case.
* **Whole-word boundaries:** Matches standalone words only (`-w`), so searching `"err"` matches `err` but ignores `errand`.
* **Deduplicated & junction-safe:** Uses `--no-follow` and real-time deduplication to prevent duplicate hits from Windows folder junctions or symlinks.
* **Smart formatting:** Preserves ANSI colors and grouped file headings in interactive terminals, and automatically switches to clean plain text when piped or redirected to a file.

## Tab Completion
* **Argument 1 (Flags or Filenames):**
  * Pressing `Tab` once completes a unique filename or flag (`--help` / `-h`).
  * Pressing `Tab` twice (`Tab` `Tab`) lists all matching files or flags when multiple candidates exist.
  * Example: `rgd -<Tab><Tab>` lists `--help  -h`; `rgd f<Tab>` completes to `rgd filecheck.txt `.
* **Argument 2 (Search Words):**
  * Pressing `Tab` once or twice does nothing, preventing accidental filename clutter while typing search words.
  * Example: `rgd filecheck.txt err<Tab>` keeps the cursor right after `err`.
* **Argument 3 (Target Directory):**
  * Pressing `Tab` once completes a unique directory name and appends a trailing `/` so you can immediately tab deeper into subfolders.
  * Pressing `Tab` twice (`Tab` `Tab`) lists matching subdirectories only (ignoring files).
  * Example: `rgd filecheck.txt error /mnt/<Tab><Tab>` lists `c/  d/`; `rgd filecheck.txt error /mnt/d<Tab>` completes to `/mnt/d/`.

## Exit Codes
* **0** : Success ΓÇö at least one match was found (or `--help` ran cleanly).
* **1** : No matches found ΓÇö search completed with zero matches.
* **2** : Usage error ΓÇö missing or empty required arguments.
* **3** : Path error ΓÇö target `search_directory` does not exist.
* **4** : Search error ΓÇö `ripgrep` encountered a runtime or regex execution error.
* **127** : Dependency error ΓÇö `ripgrep` (`rg`) is not installed or not in `$PATH`.

## Examples
* **Search the current directory (`pwd`) for a single word:**
  `rgd filecheck.txt present`
* **Search multiple whole words (matches `err`, ignores `errand`):**
  `rgd filecheck.txt "error,errors,err"`
* **Case-insensitive wildcard filename search in a specific directory:**
  `rgd "*check.log" "fail,failed,timeout" /mnt/d/Logs`
